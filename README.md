# AI Öğretmen

12 haftalık "AI Çağı Yazılım Mimarlığı" programı için yerel AI destekli öğrenme koçu.

## Kurulum
1. Gereksinimler: Java 17+, Node 18+ (içerik üretimi için).
2. Çalıştır: `./mvnw spring-boot:run` → http://127.0.0.1:8090 (AI özellikleri için `OPENROUTER_API_KEY` ortam değişkeni gerekir; anahtarsız müfredat+ilerleme çalışır).
3. Detay: `AGENTS.md` (komutlar) ve `ARCHITECTURE.md` (mimari).
